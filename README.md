# Java Game – Room Discovery

An interactive Java-based room discovery game where players enter a room, find hidden objects, and answer mathematical questions and riddles.

## 🎮 Features

* 3 random rooms
* Hidden object discovery
* Mathematical questions and riddles
* Player interaction
* Simple Java-based game mechanics

## 🛠️ Technologies Used

* **Java**
* Object-Oriented Programming (OOP)
* Eclipse WindowBuilder

## 📌 Project Overview

The game was developed as a Java programming project to demonstrate object-oriented programming, conditional logic, user interaction, and basic game development concepts.

Players enter the room and find the hiiden objects while completing mathematical challenges and riddles.

## 👩‍💻 My Role

Designed and developed the game mechanics, implemented the interactive elements, and programmed the mathematical questions, riddles, and game progression.

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/K-mariedizon/JavaGame.git
   ```

2. Open the project in a Java-compatible IDE such as IntelliJ IDEA, Eclipse, or NetBeans.

3. Run the main Java file to start the game.
